
# Electron application dummy **(EAD)**
This boilerplate was created to accelerate the start of projects using Electron + React.js. It solves the most common problems encountered when starting Electron projects and provides working examples of using native modules, creating different renderer windows, applying styles, and building complex, multi-level UI interfaces.

## connected packages
- [electron](https://www.electronjs.org)
- [@electron-forge](https://www.electronforge.io)
- [node-sqlite3](https://www.npmjs.com/package/sqlite3)
- [React](https://reactjs.org)
- [tailwind](https://github.com/tailwindlabs/tailwindcss)

#### Fork
```
> git clone https://github.com/sajera/electron-application-dummy.git
```

#### install dependencies.
```
> npm install
```

#### Run
```
> npm run start
```
